🛠️ pet.goods-infinite.com · SEO/GEO 部署实操手册

Cloudflare 放行爬虫 · 独立 GA4 · GSC 独立属性 · Bing WM · IndexNow — 分步可照做

⚠️ 总前提：这些后台操作（Cloudflare / GSC / Bing / GA）需要你本人登录账号点击，贾维斯无法代点。 但仓库侧的文件（IndexNow 密钥、注入/提交脚本）已经备好，你 push 即生效。 当前状态：全站 24 页仍挂载主站 GA G-68HRE7BJFK，必须换成 pet 独立 ID。

① Cloudflare — 放行搜索引擎与 AI 爬虫

你有终极权限 目标：让 Googlebot / Bingbot / GPTBot / ClaudeBot / PerplexityBot 拿到 200，而不是 403/000（之前抓取频繁超时就是这个原因）。

1
关掉 Under Attack 模式
旧版 UI：Overview 右侧 "I'm Under Attack" 开关 → 关掉。
新版 UI：Security → Settings → Security Level，从 "I'm Under Attack" 调到 "Medium"（或 "Essentially Off"）。
2
建 WAF 自定义规则放行爬虫 UA
Security → WAF → Custom rules → Create rule
规则名：Allow good bots
When（OR 组合）：
  • User Agent contains Googlebot
  • User Agent contains bingbot
  • User Agent contains GPTBot
  • User Agent contains ClaudeBot
  • User Agent contains PerplexityBot
  • User Agent contains Applebot / Google-Extended
Action：Allow，并勾选 Skip → 现有 WAF 规则 / 速率限制 / Bot Fight Mode（否则仍可能被拦）。
→ Deploy。
3
（增强，防 UA 伪造）按 ASN 放行
再建一条规则 Allow search engines by ASN：
  • AS Num equals 15169（Google）
  • AS Num equals 8075（Microsoft / Bing）
Action：Allow + Skip 同上。
免费版 Bot Fight Mode 无法逐类放行 AI 爬虫，靠第 2 步的 UA 规则兜底即可。
4
本地验证（关键） — 在你电脑的终端跑：
curl -A "Googlebot" -I https://pet.goods-infinite.com/ curl -A "Mozilla/5.0 (compatible; bingbot/2.0; +http://www.bing.com/bingbot.htm)" -I https://pet.goods-infinite.com/ curl -A "GPTBot" -I https://pet.goods-infinite.com/
期望：每条都返回 HTTP/2 200，且出现 cf-cache-status: HIT / server: cloudflare。 若仍 403/000，说明 WAF 规则没覆盖到，回第 2 步复查。

② 独立 GA4 — 别再共用主站 G-68HRE7BJFK

1
建 pet 独立媒体资源
analytics.google.com → Admin → Create Property
名称填 GoodsInfinite Pet (pet.goods-infinite.com) → 时区选你所在时区 → 下一步。
2
建 Web 数据流
Setup Assistant → 数据流 → Web
URL：pet.goods-infinite.com，流名称 pet prod → 复制得到的 Measurement ID（G-XXXXXXX）。
3
全站替换（脚本已备好）
在仓库根目录终端执行：
python tools/inject_ga4.py . G-你的新ID --apply
脚本会替换全部 24 页里的 G-68HRE7BJFK（每页 2 处）→ 新 ID，--apply 前可先 dry-run 预览。
⚠️ 若文章 HTML 由 ../build_pet_site.py 生成，必须同时改生成器模板，否则 regenerate 后改动被覆盖。
4
（可选）主站 GA 排除 pet 流量
在 G-68HRE7BJFK 里建"流量过滤 → 排除 → 主机名 不含 pet.goods-infinite.com"，保持主站数据干净。

③ GSC — pet 独立属性（不是主站子目录）

1
search.google.com/search-console → 添加属性
选 "网址前缀" 类型，输入 https://pet.goods-infinite.com/（独立属性，不要把 pet 当主站下的目录）。
2
验证所有权（二选一）
• 推荐 DNS TXT：在 pet.goods-infinite.com 的 DNS 加一条 TXT 记录，值用 Google 给的那串 → 不用动仓库、换服务器也不失效。
• 或 HTML 文件验证：下载 googleXXXX.html 放到仓库根目录 push 上线即可。
3
提交 sitemap
左侧 Sitemaps → 添加：https://pet.goods-infinite.com/sitemap.xml（已是 23 条，含新增 3 页）。
4
等 1–2 天看 Coverage / 索引数，确认 23 页逐步被收录。

④ Bing Webmaster Tools + IndexNow

1
bing.com/webmasters → 添加站点 pet.goods-infinite.com
验证同 GSC：DNS TXT / XML 文件 / Meta 标签 任选。
2
提交 sitemap：Sitemaps 添加 https://pet.goods-infinite.com/sitemap.xml。
3
IndexNow 密钥已生成
仓库根已放 indexnow-<随机key>.txt（内容是 key 本身）。部署后确认可访问：
https://pet.goods-infinite.com/indexnow-<key>.txt
主站曾遇 Cloudflare WAF 403 导致 IndexNow 失败 —— 模块①放行 Bingbot 后一般即恢复。
4
推送（脚本已备好）
首次全量：
python tools/submit_indexnow.py .
之后仅推改动页：
python tools/submit_indexnow.py https://pet.goods-infinite.com/about/ https://pet.goods-infinite.com/medical-review/
⚠️ IndexNow 是"增量即时推送"，别每次部署狂推全量（会被限流）。

① 爬虫 200 不再被拦 → SEO/GEO 才真正生效；
② pet 流量独立计量，不再混进主站报表；
③ GSC/Bing 各自独立监控收录；
④ 新内容上线被搜索引擎秒级发现（IndexNow）。
全部 push 后，回到模块①第 4 步的 curl 验证，确认 200 即大功告成。
