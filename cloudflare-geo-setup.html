📋 免费版能力对照（你"没有"的那些是付费，直接跳过，不用管）
✅ 免费版有：Security Level（关 Under Attack）、5 条 WAF Custom Rules、Bot Fight Mode 开关。
✖ 免费版没有（我上版手册写超纲了，抱歉）：Super Bot Fight Mode、AI Crawl Control、用 Skip 绕过 Bot Fight Mode、按 Bot Score 精细放行。
👉 所以正确姿势是：关掉 Bot Fight Mode + 用 WAF Allow 规则放行，而不是去碰上面那些付费功能。

① Cloudflare（免费版适用）— 让爬虫拿到 200，而不是被 JS 挑战挡掉

免费版重点 目标：Googlebot / Bingbot / GPTBot / ClaudeBot / PerplexityBot 都能正常抓取。你之前抓取频繁 000/403，最大嫌疑是免费版 Bot Fight Mode 在误伤爬虫。

1
关掉 Under Attack 模式
Security → Settings → Security Level，从 "I'm Under Attack" 调到 "Medium"（或 "Essentially Off"）。
如果你从没开过 Under Attack，这步就是确认它没开着。
2
🔴 关键：关闭 Bot Fight Mode（免费版不可配置，开着必误伤）
Security → Settings → 顶部过滤选 "Bot traffic" → 找到 Bot Fight Mode → 关掉（Off）。
为什么必须关：免费版 Bot Fight Mode 不能自定义、也不能用规则 Skip 绕过。它会对未经验证的爬虫（GPTBot / ClaudeBot / PerplexityBot）甚至 Googlebot 发起 JS 挑战，爬虫完成不了就等于被墙；实测有站点因此 Google 收录几天内暴跌。这正是你之前抓 pet 站出现 000/403 的最可能根因。关掉它，比写任何规则都重要。
3
用 WAF Custom Rule 放行爬虫 UA（免费版有 5 条，足够）
Security → WAF → Custom rules → Create rule
规则名：Allow search & AI crawlers
When（OR 组合，字段 User Agent）：
  • contains Googlebot   • contains bingbot   • contains GPTBot
  • contains ClaudeBot   • contains PerplexityBot   • contains Applebot / Google-Extended
Action：Allow → Deploy。
免费版 Bot Fight Mode 已关（第 2 步），这里 Allow 足够让 AI 爬虫通过；Googlebot/Bingbot 本身是"已验证爬虫"本就豁免，加这条是双保险。
4
本地验证（最关键的一步） — 在你电脑终端跑：
curl -sSI -A "Googlebot" https://pet.goods-infinite.com/ | grep -iE "HTTP/|cf-mitigated|server:" curl -sSI -A "GPTBot" https://pet.goods-infinite.com/ | grep -iE "HTTP/|cf-mitigated"
期望：HTTP/2 200，且不要出现 cf-mitigated: challenge。
若仍 403 / 出现 challenge → 说明 Bot Fight Mode 没关干净或 WAF 还有拦截规则，回第 2 步复查。

② 独立 GA4 — 别再共用主站 G-68HRE7BJFK

1
建 pet 独立媒体资源
analytics.google.com → Admin → Create Property
名称填 GoodsInfinite Pet (pet.goods-infinite.com) → 时区选你所在时区 → 下一步。
2
建 Web 数据流
Setup Assistant → 数据流 → Web
URL：pet.goods-infinite.com，流名称 pet prod → 复制得到的 Measurement ID（G-XXXXXXX）。
3
全站替换（脚本已备好）
在仓库根目录终端执行：
python tools/inject_ga4.py . G-你的新ID --apply
脚本替换全部 24 页里的 G-68HRE7BJFK（每页 2 处）→ 新 ID，--apply 前可先 dry-run 预览。
⚠️ 若文章 HTML 由 ../build_pet_site.py 生成，必须同时改生成器模板，否则 regenerate 后改动被覆盖。
4
（可选）主站 GA 排除 pet 流量
在 G-68HRE7BJFK 里建"流量过滤 → 排除 → 主机名 不含 pet.goods-infinite.com"，保持主站数据干净。

③ GSC — pet 独立属性（不是主站子目录）

1
search.google.com/search-console → 添加属性
选 "网址前缀" 类型，输入 https://pet.goods-infinite.com/（独立属性，不要把 pet 当主站下的目录）。
2
验证所有权（二选一）
• 推荐 DNS TXT：在 pet.goods-infinite.com 的 DNS 加一条 TXT 记录，值用 Google 给的那串 → 不用动仓库、换服务器也不失效。
• 或 HTML 文件验证：下载 googleXXXX.html 放到仓库根目录 push 上线即可。
3
提交 sitemap
左侧 Sitemaps → 添加：https://pet.goods-infinite.com/sitemap.xml（已是 23 条，含新增 3 页）。
4
等 1–2 天看 Coverage / 索引数，确认 23 页逐步被收录。

IndexNow 密钥已生成
