# pet-site-

Vet-informed pet care guides for dogs & cats, with a product catalog matched to each
problem. Content layer for the **GOODS INFINITE** US TikTok Shop.

- Static site, no build step.
- Publish directory for Cloudflare Pages: `/` (repository root).
- Build command: *(none)*.
- Canonical domain: https://pet.goods-infinite.com
- Source generator: `../build_pet_site.py` (regenerate, then commit).

All "Buy" buttons link to the official TikTok Shop; this repo is the SEO/GEO content hub.
Content is educational only and not veterinary advice.
